1. Information we collect

The Family Todo app stores an anonymous account and family data in Firebase (Google) so devices can stay in sync. Synced data includes family name, invite code, member name, emoji, color, and points, tasks, timer records, chat messages, and point history. The app does not require email, phone number, or real-name login, and it does not use advertising or analytics SDKs.

This website does not create accounts and does not set advertising cookies.

2. Where data is stored

The app uses an on-device Room database as an offline cache. When the device is online, family data for the same invite code is synced with Cloud Firestore. Uninstalling the app deletes local records on that device. A cloud family room used by other members may remain.

3. Third parties

Google Firebase (Authentication and Cloud Firestore) is the processor for family sync. Data is not shared with advertising networks. Firebase locations and security follow Google’s policies.

4. Family chat and invite codes

Chat, tasks, and points sync only among devices that joined with the same six-digit invite code. Anyone who knows the code can enter the family room, so do not share it outside the family. This is not a public community or searchable board.

5. Children

This service is not directed at children under 13, and we do not knowingly collect personal information from children.
