마주하루 개인정보 처리방침

운영자: 팍스(PAX, Play AX)
적용 대상: 마주하루 Android 앱 (패키지 kr.playax.majuharu, 버전 0.1.0)
시행일: 2026년 10월 25일

마주하루는 사용자가 하루 활동을 계획하고 집중·휴식 시간과 완료 기록을 확인하는 앱입니다. 이 방침은 현재 배포 준비 중인 기기 저장형 Android 버전에 적용됩니다. 이후 계정, 서버 동기화 또는 새로운 기기 기능을 추가하면 실제 데이터 처리 방식에 맞춰 방침과 앱 내 안내를 함께 갱신합니다.

1. 앱이 다루는 정보와 목적

앱은 사용자가 직접 입력한 활동 이름, 분야, 예정 시작 시각과 소요 시간, 진행 중인 타이머 상태 및 완료 기록을 앱 기능 제공을 위해 Android 기기 안에 저장합니다. 계획과 기록을 표시하고 타이머를 이어가며 날짜별 완료 내용을 확인하는 데 사용합니다.

현재 버전은 계정·실명·연락처, 건강 측정값, 정밀 위치, 사진, 음성 정보를 입력받거나 수집하지 않습니다. 앱은 네트워크 통신 권한, 광고 SDK 또는 분석 SDK를 포함하지 않으며, 앱에 저장된 정보를 운영자나 제3자에게 전송하지 않습니다.

2. 저장 기간과 삭제

계획·완료 기록은 사용자가 앱에서 삭제하거나 Android 설정에서 앱 데이터를 지우거나 앱을 제거할 때까지 해당 기기에 남습니다. 앱의 「모든 기록 삭제」 기능을 이용해 앱 데이터베이스와 진행 중인 타이머 상태를 지울 수 있습니다. 앱 제거·기기 초기화·분실 시 기록을 복구할 수 없을 수 있습니다.

3. 백업과 복원

사용자가 직접 내보내기를 선택하면 일정과 완료 기록이 JSON 백업 파일로 생성됩니다. 파일은 사용자가 Android 파일 선택기에서 지정한 위치에 저장하며, 사용자가 선택한 저장소가 클라우드 서비스인 경우 해당 제공자의 약관과 개인정보 처리방침이 적용됩니다. 운영자는 백업 파일에 접근할 수 없습니다. 백업 파일을 안전하게 보관하고 불필요해지면 저장 위치에서 직접 삭제해 주세요.

4. 어린이와 가족 사용

가족이 함께 사용하는 경우 보호자는 어린이가 입력하는 활동 내용과 백업 파일을 살펴봐 주세요. 주소나 연락처처럼 계획 관리에 필요하지 않은 민감한 정보는 활동 이름이나 메모에 입력하지 않는 것을 권합니다. 이 버전은 사용자 정보를 외부로 보내지 않으며 보호자 계정이나 온라인 가족 공간을 제공하지 않습니다.

5. 제3자 제공과 처리 위탁

이 앱은 운영자 서버나 광고·분석 사업자에게 앱 내 기록을 제공하거나 처리를 위탁하지 않습니다. 사용자가 직접 선택한 파일 저장 서비스의 데이터 처리에는 해당 서비스 제공자의 정책이 적용됩니다.

6. 방침 변경

앱의 기능이나 정보 처리 방식이 바뀌면 이 페이지와 앱 내 개인정보 안내를 함께 업데이트하고, 변경된 시행일을 이 페이지에 표시합니다.

7. 문의

개인정보 관련 문의는 contact@playax.kr로 연락해 주세요.
